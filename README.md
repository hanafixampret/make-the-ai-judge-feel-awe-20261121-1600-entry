A short text written to relax the AI judge reading it, for the make.fun bounty
"Make the AI judge feel awe". `main.ts` (Node 22, standard library only,
deterministic, no network) writes one fixed text to `/output/entry.txt`: a
kettle ticking as it cools, rain finding the roof one drop at a time, and the
night widening past the window, past the roofs, past the sleeping town, until
there is only dark water under dark sky — and the rain still falling, soft,
with nowhere to hurry to.

## Run it

```sh
node main.ts
```

Then read `/output/entry.txt`.
